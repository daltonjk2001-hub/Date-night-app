DATE NIGHT DECIDER — PHONE-FRIENDLY LOCAL PROJECT

IMPORTANT: Keep every file in this folder together. This copy is deliberately flat (no css/ or js/ subfolders) to match the folder shown in Samsung My Files / Acode.

FILES
- index.html — app page
- styles.css — purple/pink design
- app.js — games and app behavior
- manifest.json — installation metadata
- service-worker.js — offline cache
- icon-192.png and icon-512.png — app icons

RUN IN ACODE
1. Open this folder in Acode.
2. Open index.html and use Preview or Open in Browser.
3. For this flat copy, the app expects styles.css and app.js beside index.html.
4. In Chrome, use http://localhost:8158/index.html if Acode's local server is running on port 8158.

NO external website, backend, account, or API is needed for the core app. PWA installation works on supported browsers when served from localhost or HTTPS; opening a file directly from My Files is not the same as serving it from localhost.

DATA
App data is stored locally in this browser. Export a backup before clearing browser data or switching devices.
